VPKit swift package manager distribution
===
Binary distribution of VPKit.xcframework (source: https://github.com/veepionyc/VPKit2.0).

    .package(url: "https://github.com/veepionyc/VPKit-spm", from: "2.11.0")

Products: `VPKit-dynamic` (dynamic xcframework) or `VPKit-static` (static xcframework).
Both embed the privacy manifest. Since 2.11.0 there is no AWS dependency.
